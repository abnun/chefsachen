# Installationsanleitung: Kleinunternehmer-Verwaltung

Diese App ist (noch) nicht mit einem offiziellen Entwickler-Zertifikat signiert.
Dein Betriebssystem zeigt deshalb beim allerersten Start eine
Sicherheitswarnung an — das ist normal und kein Zeichen für ein Problem mit
der App. Du musst die Warnung nur **einmalig** bestätigen.

## macOS

1. Lade die Datei `Kleinunternehmer-Verwaltung_x.y.z_universal.dmg` herunter
   und öffne sie.
2. Ziehe die App in den `Programme`-Ordner (wie bei jeder Mac-App).
3. **Nicht per Doppelklick öffnen** — stattdessen:
   - Im `Programme`-Ordner mit der **rechten Maustaste** (bzw. bei Trackpad
     mit zwei Fingern) auf „Kleinunternehmer-Verwaltung" klicken.
   - Im Menü **„Öffnen"** auswählen.
   - Im folgenden Dialog nochmal auf **„Öffnen"** klicken.
4. Ab jetzt lässt sich die App ganz normal per Doppelklick starten.

**Falls das Rechtsklick-Menü keine „Öffnen"-Option zeigt** (neuere
macOS-Versionen verstecken das teilweise): Nach dem ersten (fehlgeschlagenen)
Doppelklick-Versuch unter **Systemeinstellungen → Datenschutz & Sicherheit**
ganz nach unten scrollen — dort erscheint ein Hinweis auf die blockierte App
mit einem Button **„Trotzdem öffnen"**.

## Windows

1. Lade die Datei `Kleinunternehmer-Verwaltung_x.y.z_x64-setup.exe` (oder die
   `.msi`-Datei) herunter und führe sie aus.
2. Windows zeigt einen blauen Bildschirm **„Der Computer wurde durch Windows
   geschützt"**.
3. Auf **„Weitere Informationen"** klicken.
4. Auf den nun erscheinenden Button **„Trotzdem ausführen"** klicken.
5. Die Installation läuft danach ganz normal weiter.

## Warum diese Warnung erscheint

Sowohl Apple als auch Microsoft verlangen für eine "stille", warnungsfreie
Installation ein kostenpflichtiges Entwickler-Zertifikat pro Plattform. Diese
App wird aktuell im kleinen Kreis weitergegeben, ohne dass sich dieser Aufwand
schon lohnt — an der Sicherheit der App selbst ändert das nichts, die
Warnungen prüfen nur, ob der Herausgeber offiziell verifiziert ist, nicht den
Inhalt der App.

## Deine Daten

Alle Daten (Kunden, Rechnungen, Angebote) werden ausschließlich lokal auf
deinem Rechner in einer Datei gespeichert — es gibt keinen Server, keine
Cloud-Anbindung und keine Übertragung an Dritte.
